# Strata-Cobot-E-Yantra
Autonomous multi-robot mining pipeline for eYRC 2026-27 (Strata Cobot). Built with ROS 2 &amp; Gazebo, it coordinates a mobile rover (path planning, obstacle avoidance, ore hauling) and a robotic arm (ore classification, pose estimation, velocity servoing) to execute a fully autonomous field-to-facility handoff and sorting workflow.
